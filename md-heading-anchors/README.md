# md-heading-anchors

기준 마크다운 파일의 **헤딩 앵커**를 변형본 파일들에 그대로 이식한다.

같은 문서를 여러 변형본으로 나눠 관리하면(로케일별, 환경별) 헤딩 구조는 같지만 헤딩 문구는 달라진다.
그런데 문서 밖에서 특정 섹션으로 걸어오는 딥링크는 앵커를 본다. 기준 파일에만 앵커가 있고 변형본에는
없으면, 링크를 눌러도 엉뚱한 섹션으로 떨어진다.

앵커를 손으로 옮기는 건 지루하고, 지루한 만큼 틀린다. 헤딩이 수십 개면 한두 개는 빠지거나 다른 섹션의
ID가 붙는다. 그리고 다음 배포에 또 옮겨야 한다.

## 하는 일

**헤딩을 문구가 아니라 등장 순서로 맞춘다.** 변형본의 i번째 헤딩은 기준 파일의 i번째 헤딩의 앵커를 받는다.
문구가 달라도 되는 이유가 여기 있다.

```
기준 파일                                    변형본 (적용 후)
────────────────────────────────────         ────────────────────────────────────
                                             <a id="log-collector"></a>
## 로그 수집기 { #log-collector }            ## 수집기 { #log-collector }

                                             <a id="list-collectors"></a>
### 수집기 목록 보기                          ### 수집기 목록 조회
      { #list-collectors }                         { #list-collectors }

<a id="list-collectors-request"></a>         <a id="list-collectors-request"></a>
#### 요청                                     #### 요청
```

기준 파일이 어떤 헤딩 레벨에 무엇을 붙여 뒀는지 그대로 따라간다. `##`에는 `<a id>`와 `{ #id }` 둘 다,
`####`에는 `<a id>`만 — 그런 구분이 있으면 그 구분까지 복제된다. 도구가 정책을 정하지 않는다.

## 쓰기

```bash
md-heading-anchors 기준파일 변형본 [변형본 ...]
md-heading-anchors -n 기준파일 변형본 ...     # 바꾸지 않고 보고만
```

```bash
$ md-heading-anchors ko/guide.md ko/guide-{a,b,c}.md
ko/guide-a.md: 32 anchor(s), 13 id suffix(es)
ko/guide-b.md: 32 anchor(s), 13 id suffix(es)
ko/guide-c.md: already in sync
```

## 지키는 것

- **전부 되거나 아무것도 안 된다.** 대상 전체를 먼저 계산하고, 하나라도 실패하면 한 파일도 쓰지 않는다.
  마지막 파일에서 헤딩 개수가 어긋났을 때 앞 파일들이 이미 바뀐 채로 남는 상황을 만들지 않는다.
- **헤딩 줄과 앵커 줄만 건드린다.** 본문·공백·파일 말미 개행은 원본 바이트 그대로 둔다. 말미 개행이
  없는 파일에 개행을 붙이지 않는다 — 그것도 diff에 남는 변경이다.
- **두 번 돌려도 같다.** 이미 앵커가 있는 헤딩은 건너뛴다. `<a id="x">`, `<a id='x'>`, `<a name="x">`
  모두 "이미 있음"으로 본다.
- **구조가 다르면 멈춘다.** 헤딩 개수나 레벨이 어긋나면 무엇이 몇 개인지 말하고 종료한다. 순서 매칭은
  구조가 같다는 전제 위에서만 옳으므로, 전제가 깨지면 추측하지 않는다.
- **코드 펜스 안의 `#`은 헤딩이 아니다.** ` ``` `과 `~~~`, 들여쓴 펜스를 추적한다.

## 안 하는 것

- 앵커 ID를 **만들지** 않는다. 기준 파일에 있는 것만 옮긴다. 기준 파일에 앵커가 없으면 할 일이 없다.
- 기준 파일을 고치지 않는다.
- 변형본을 짝지어 찾아주지 않는다. 어떤 기준 파일에 어떤 변형본이 딸리는지는 셸 글로브로 넘긴다.

## 설치

```bash
ln -sf ~/dev-tools/md-heading-anchors/md-heading-anchors ~/bin/md-heading-anchors
```

Python 3만 있으면 된다. 외부 패키지를 쓰지 않는다.
